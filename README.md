# 蔵の広報アシスタント（HTMLモック）

酒蔵ツーリズム企画コンペ用のデモ。蔵人が「写真＋ひとことメモ」を入れ、「届けたい相手」と「出力形式」を選ぶだけで、SNS投稿（文章＋投稿用画像）ができあがる流れを見せます。

## 動かし方（発表本番）

`index.html` をブラウザで開くだけです。ビルドもサーバーも不要です。
生成は事前に用意した文面を返す「ダミー」モードで動きます（ヘッダー右上の切り替えが「ダミー」になっていることを確認してください）。

## 3分デモの流れ

1. **蔵の情報**：サンプルが入っているので、そのまま「次へ」
2. **素材**：写真を選ぶ（選ばなければサンプル画像）。メモもサンプルのまま「次へ」
3. **相手と形式**：相手Aを選んで「投稿を作る」
4. **結果**：Instagram風のプレビューを見せ、「文章をコピー」
5. **見せ場**：「相手を変えて作り直す」→ 相手B（X投稿）→ 相手C（英語のInstagram）と切り替え、同じ素材から文面・言語・語り口が変わることを見せる

| 相手 | おすすめ形式 | 変わるところ |
| --- | --- | --- |
| A 20〜30代女性／日本酒好き・外飲み派 | Instagram | 情景と季節感、やわらかい語り口 |
| B 40〜60代男性／晩酌・地酒好き | X（140字以内） | 銘柄名・味・燗など具体的、簡潔 |
| C 訪日観光客／日本文化に関心 | Instagram（英語） | 英語、「ひやおろし」の説明つき |

相手を選ぶとおすすめ形式が自動で選ばれます（手動で変更も可）。用意のない組み合わせ（例：B×Instagram）も表示できます。
「別の案を出す」で、同じ相手の2案目に切り替わります。

## 文面を差し替えたいとき

`index.html` 内の `POSTS`（文面）と `AUDIENCES`（相手の定義・工夫の説明）を編集します。
文面中の `{kura}` は「蔵の情報」の蔵名に置き換わります。サンプルの「霞川酒造」は架空の蔵です。実在の蔵名を使う場合は、チームで許可を確認してから差し替えてください。

## 任意：Claude API 接続モード

ブラウザにAPIキーを置かないよう、FastAPI の薄いバックエンド（`server.py`）経由で呼び出します。

```sh
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
uvicorn server:app --port 8000
```

`http://localhost:8000/?mode=api` を開くと API モードで起動します（ヘッダーの切り替えでも変更可）。
API に接続できない場合は、自動でダミー文面に切り替えて注記を表示します。

- `POST /generate`
  - 入力：`{profile, memo, audience, language, format}`
  - 出力：`{caption, hashtags, banner_text}`（`banner_text` は「1行目／2行目」）
- モデルは `claude-opus-5`。拒否時に別モデルで再実行するサーバー側フォールバックを有効にしています。

## スコープ外

ログイン、データ保存、SNSへの自動投稿、動画生成（UI上は「今後対応予定」表示のみ）、分析、投稿スケジュール管理。
